## 스토어 설명

**간단한 설명** (80자 이내)

> EPUB, PDF, HWP, DOCX, Markdown 문서를 한 앱에서 읽고 기록하는 리더

**자세한 설명**

> Mins Reader는 휴대폰에 있는 여러 형식의 문서를 한곳에서 읽는 앱입니다.
>
> ■ 지원 형식
> - EPUB 전자책
> - PDF
> - HWP, HWPX 문서 보기(원본 쪽 보기 지원)
> - DOCX 문서 보기
> - Markdown 읽기와 편집
>
> ■ 읽기 기능
> - 읽던 위치 자동 저장, 책갈피, 형광펜과 메모
> - 문서 안 검색
> - 글꼴, 글자 크기, 화면 테마 설정
> - 다른 앱에서 "열기"나 "공유"로 바로 열기
>
> ■ 기록 옮기기
> - 클라우드 폴더에 둔 동기화 파일로 다른 기기와 읽기 기록 맞추기
> - 기록 내보내기와 가져오기
>
> ■ 개인정보
> - 회원가입, 광고, 데이터 수집이 없습니다. 문서와 기록은 기기 안에만 저장됩니다.
>
> 본 제품은 한글과컴퓨터의 한/글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. "한글", "HWP"는 (주)한글과컴퓨터의 상표이며, Mins Reader는 (주)한글과컴퓨터와 관련이 없습니다.

## 데이터 보안 양식

| 질문 | 답변 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | 아니요 |
| 전송 중 데이터 암호화 | 해당 없음(전송하는 데이터 없음) |
| 데이터 삭제 요청 방법 | 해당 없음(수집하지 않음). 앱을 삭제하면 기기 안 데이터도 지워짐 |

근거: 외부 서버로 보내는 요청이 없고, 권한은 `INTERNET`(Capacitor 기본) 하나뿐입니다. 동기화 파일은 이용자가 고른 파일에 쓰는 것이라 Play 정책상 "수집"이 아닙니다. 코드에 네트워크 전송을 추가하면 이 답변을 다시 검토합니다.

## 남은 일

1. 개인정보처리방침의 `[연락처 이메일]`을 Play 개발자 연락처 이메일로 바꾼다.
2. 개인정보처리방침을 누구나 열 수 있는 웹 페이지로 올린다. 저장소가 공개라면 GitHub의 이 파일 주소를 써도 되고, GitHub Pages나 Google Sites도 된다(PDF는 안 됨).
3. 휴대폰 스크린샷 2장 이상.
4. 오픈소스 고지(`open-source-notices.md`)와 HWP 출처 문구를 앱 안 "앱 정보" 화면에서도 볼 수 있게 한다(Apache-2.0과 OFL은 함께 배포할 것을 요구).
5. 개인 개발자 계정이면 비공개 테스트(테스터 12명, 14일) 뒤 프로덕션 공개.
